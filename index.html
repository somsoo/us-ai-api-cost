🧮 How the estimate works

  • Per request: input tokens ÷ 1,000,000 × input price + output tokens ÷ 1,000,000 × output price. Example: 1,000 input and 500 output tokens at $2 and $10 per 1M tokens cost $0.002 + $0.005 = $0.007.
  • Per day, month and year: per request × requests per day, then × days per month, then × 12.
  • Batch: all three providers list their Batch API at 50% off both input and output for these models.
  • Long prompts: the GPT-6 models here charge their long-context prices when a request has more than 272,000 input tokens, and Gemini 3.1 Pro Preview when a prompt has more than 200,000 tokens. The Claude models here keep the same price across their context window.
  • Price changes: Google lists a higher Gemini 3.8 Flash price starting January 1, 2027. The calculator uses the price for today’s date and shows what the change means for you.

❓ Frequently asked questions

How is the cost calculated?

Cost per request equals input tokens divided by 1,000,000 times the input price, plus output tokens divided by 1,000,000 times the output price. The daily cost is that times your requests per day, the monthly cost is the daily cost times your days per month, and the yearly cost is 12 months. Batch halves both prices.

How current are the prices?

The built-in prices were checked on each provider's official pricing page on September 30, 2026, using standard pay-as-you-go rates in US dollars. Prices change often, so confirm them before you budget, or enter your own prices with Custom prices.

How many tokens is my text?

A common rule of thumb for English is about 4 characters or 0.75 words per token. Paste sample text into the estimator to apply that rule. Each model family counts tokens differently; Anthropic notes that Claude 4.7 and later models produce about 30% more tokens for the same text.

What are long-context prices?

Some models charge more when a single request has a very long input. The GPT-6 models listed here use higher prices above 272,000 input tokens, and Gemini 3.1 Pro Preview above 200,000. The calculator switches to those prices when your input tokens per request pass the limit.

What is not included?

Taxes, prompt caching discounts, tool fees such as web search, image and audio tokens, regional or data residency surcharges and negotiated discounts are not included. Some providers bill thinking tokens as output, so include them in your output tokens.

⚠️ Please note

These are estimates, not quotes or bills. Actual charges depend on the exact tokens counted by each provider, your account, region and features used, and prices can change at any time. Check the provider’s current pricing page before making budget decisions.
